# pi Enable Image

A [pi coding agent](https://github.com/earendil-works/pi-coding-agent) extension that lets text-only models work with images. It registers a `read-image` tool: the agent passes it a path to an image file, and the tool returns a thorough text description generated by a multimodal backup model.

## Quickstart

Install inside pi:

```bash
pi install https://github.com/eleqtrizit/pi-enable-image.git
```

Then run `/image-backup-model` once to pick the multimodal model used to describe images. The choice persists in `~/.pi/image-backup-model.json`.

## How it works

- The tool takes one argument: `path` to an image file (png, jpg, jpeg, gif, webp, or bmp). Relative paths resolve against the session's working directory.
- Ask the agent to use it, for example: "Run read-image on /tmp/screenshot.png and tell me which field in this dialog fails validation."
- The tool validates the file, sends it to the backup model, and returns the description: visible text, layout, UI elements, and anything needed to act on the contents.
- The tool's result carries the side query's token usage, so session totals stay accurate.
- The tool is active only while the current model cannot view images. Run `/model` to switch, and pi enables or withdraws `read-image` automatically, so image-capable models never see it.
- Every failure returns an error message the agent can read and act on: missing file, unsupported format, unset or unavailable backup model, missing auth, or a provider error.

## Development

```bash
npm install
npm run typecheck
npm test
pi -e ./extensions/index.ts     # load the extension directly from the repo
```

After `npm install`, docs and examples ship inside the pi package under `node_modules/@earendil-works/pi-coding-agent/docs/`.
